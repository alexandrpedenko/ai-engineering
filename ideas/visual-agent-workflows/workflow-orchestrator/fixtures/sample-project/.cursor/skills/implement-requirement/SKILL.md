# Implement a requirement

Use this when you are asked to implement one requirement from a requirements file.

1. Find the requirement by its number (`R1`, `R2`, …) and read its acceptance check.
2. Write the smallest change in `src/` that makes the acceptance check pass.
3. Add a test next to the code you changed (`<name>.test.ts`) that does what the acceptance check says.
4. Don't touch files outside `src/`, and don't change code the requirement doesn't need.
5. If the requirement or its check is unclear, stop and say what is unclear instead of guessing.
