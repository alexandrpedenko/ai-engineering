# Architecture review

Use this when you are given requirements and a proposed design.

1. For each requirement, say which part of the design satisfies it. Mark any requirement no part covers.
2. Name the three biggest risks: what could fail, how likely it is, what it would cost.
3. For each risk, propose the smallest change that reduces it.
4. Keep it under two pages. Link requirements by their number (`R3`).
